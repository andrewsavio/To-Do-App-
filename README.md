**To Do List Application**
**To run the web page follow the below intructions**:
1. javac ToDoApp.java **# This compiles the java file into byte code**
2. java ToDoApp.java **# This is used to run the webpage in localhost**
By default the Web Application runs in the following localhost configuration
http://localhost:8000/ **# This can change if the port no is already occupied by anyother processes.**
